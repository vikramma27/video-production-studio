02 / THE PRODUCTION ENGINES

Choose the right
tool for the frame.

No single renderer has to do everything. The studio assigns each scene to the engine that best serves its visual language, determinism and production cost.

ENGINE / 01FIRST-CLASS ENGINE

React compositions.
Editorial control.

Remotion is a first-class production engine for component-driven compositions, reusable scene systems, data-led visuals, launch films and complex motion layouts. It is not limited to occasional specialist scenes.

Cinetic / the launch-film specialist

Approved for a controlled pilot: launch films, update videos, trailers and social cut-downs. Its 34-scene Remotion starter is a candidate library — not yet tested or installed. It does not replace the studio's story engine.

PILOT APPROVED · NOT INSTALLED

Cinematic Skill / documentary camera language

A Python + Skia specialist for narration-led explainers: drawn diagrams, maps, typography, annotations and virtual-camera travel. Approved for a 60–90 second code-only pilot. Archive photos, downloaded assets and AI stills are excluded from final renders.

03 / THE OPERATING METHOD

From first idea
to finished frame.

A production system with deliberate approval gates. Creative judgement stays human-led; repeatable work is pushed into deterministic local tools.

01 / REFERENCE INTELLIGENCE

Study the craft.

Analyse representative videos shot by shot. Record pacing, camera language, lighting, acting and visual fingerprints.

Analysis only · never copied assets
02 / CHARACTER ATELIER

Build the originals.

Develop two distinct protagonists in Blender: turnarounds, expressions, body actions and playable animation pilots.

Iterate → user approval → freeze
03 / VOICE IDENTITY

Find the voice.

Audition local voice candidates against the same script. Pin exact model, weights, settings and pronunciation profile.

Consent + licence checks
04 / CHANNEL IDENTITY

Give it a world.

Create original names, channel art, typography, palette, thumbnail grammar and a coherent visual bible.

Original brand · approved version
05 / STORY ROOM

Build the slate.

Generate a broad idea pool, curate 30–60 approved concepts and organise user-selected one- or two-week batches.

Human editorial control
06 / LOCAL PRODUCTION

Make it repeatable.

Render with the right engine, assemble with FFmpeg, inspect contact sheets and playback, then prepare delivery packages.

Manual publishing · QA before release

The production philosophy

Make it original.
Make it repeatable.

Claude Code or Codex handles direction and judgement. Local tools do the repeatable work. Every scene earns its place. Every identity is approved. Every finished video is reviewed by a human before it leaves the studio.
