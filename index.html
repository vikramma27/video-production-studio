One studio. Clear roles.

Purpose-built layers work together. No single agent is forced to do everything; each part has a defined job.

Intelligence layer

THE PERMANENT RULE

Don't spend intelligence on work that automation can do.

Reuse what exists. Prefer deterministic local execution. Call specialist local models when appropriate. Reserve hosted reasoning for creative judgement, language, ambiguity and exceptions.
