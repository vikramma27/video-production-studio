The problem worth solving

Intelligence
is too expensive
to waste.

Not every production decision needs a reasoning model. Not every operation needs a conversation.

The goal isn't to make an AI agent click faster. It's to stop asking an AI agent to do work that a reliable local tool can finish in milliseconds.

×
The old pattern

Agent does everything

Repeated file handling, media probing, conversions, exports and checks consume context, time and hosted-model usage.

↗
The studio pattern

Intelligence directs. Tools execute.

Agents make the decisions that need judgement. Scripts, local models and production tools handle predictable work in batches.

The architecture

Two planes.
One studio.

One layer decides what should happen. The other makes it happen. The boundary is deliberate, measurable and designed to keep getting stronger.

01 — INTELLIGENCE PLANE

The brains.
Not the workforce.

Claude Code and Codex own the brief, research, creative direction, technical decisions, orchestration and exception handling. They build reusable systems instead of repeating manual work.

  • Creative judgement
  • Planning & reasoning
  • Exception diagnosis
  • Quality review
Think · Direct · Improve
02 — LOCAL EXECUTION PLANE

The workers.
Built for throughput.

Deterministic scripts, specialist local models and media engines perform the repeatable operations. Stages are batchable, cache-aware, independently rerunnable and inspectable.

  • PowerShell · Python · Node
  • FFmpeg · ffprobe
  • Local speech & vision models
  • Motion · 3D · rendering
Run · Cache · Validate

The rule that changes the economics

Automate
the repeat.
Protect
the craft.

When a task is predictable, make it a script. When a specialist model can do it locally, route it there. Save agent reasoning for the choices that actually benefit from intelligence.

One source of truth. Many clean runs.
The specialist bench

The right tool.
The right job.

Tools are selected for their strengths, not collected for their logos. This is the intended division of labour in the production stack.

Orchestration
Claude Code · Codex
Creative direction, planning, implementation, review and exception handling.
Motion & web scenes
HyperFrames · GSAP · Remotion
Timeline-aware motion, precise animation and data-driven visual sequences.
3D & compositing
Blender · Three.js
Dimensional scenes, technical objects, camera work and rendered visual assets.
Media engine
FFmpeg · ffprobe
Batch conversion, encoding, probing, assembly and repeatable media operations.
Speech & language
faster-whisper · Chatterbox
Local transcription and narration workflows, subject to hardware and voice-quality tests.
Editorial systems
Herk Edit Kit · Video Shotcraft
Reusable editing methods, structured cut decisions and visual direction references.

The stack is an evolving selection, not a promise that every listed component is installed or production-ready. Local execution, licensing, compatibility and quality are verified before adoption.
