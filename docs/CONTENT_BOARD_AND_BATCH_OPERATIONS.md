# Content Idea Board and Batch Operations

## Idea generation
For 30–60 desired accepted ideas, normally generate 2–4x candidates (e.g. 120–180 for a 60-idea target). Diversify genre, hook, protagonist, stakes, emotional arc, setting, format and production complexity. Deduplicate similar premises and flag derivative/risky concepts.

Each card includes idea ID, channel, working title, premise, first-seconds hook, conflict/payoff, emotional tone, genre, format/duration, originality notes, character/location/prop dependencies, complexity/render demand, series potential, risks and user decision state.

## Review board
Columns: Inbox, Candidate, Shortlist, Accepted, Calendar, In production, Review, Ready for upload, Published, Rejected and Deferred. Support accept, reject, revise, shortlist, merge, defer, reorder and lock. Retain rejection reasons; do not silently reintroduce rejected ideas.

Filter by channel, format, genre, complexity, duration, character, status and planned week. Lock 30–60 ideas before production scheduling.

## Weekly/two-week planning
After calendar approval, ask whether the next batch is one week or two weeks and how much local machine time is available. Propose a balanced batch respecting channel/format mix, dependencies, approved assets, render estimates and availability. User approves before execution.

## Local job board
The laptop is the execution host. Show queued, running, awaiting approval, blocked, failed, paused and complete. Persist state. Support pause/resume/cancel, graceful shutdown, retry policy, logs, progress, resource load and output previews. Distinguish a render running locally from an agent awaiting input.

## Parallelism and laptop-open operation
Parallelize independent research, script QA, metadata, narration preparation and asset checks. Limit Blender GPU renders based on measured VRAM, RAM and thermals; default to one heavy render until tests justify more. Use isolated per-shot workspaces and disjoint outputs. Queue must survive restart; provide stop-after-current-job.

## Publishing
Prepare exports, thumbnail, captions, title/description options, metadata and recommended slot. User uploads and schedules manually. No automatic publishing or YouTube credential storage in v1.
