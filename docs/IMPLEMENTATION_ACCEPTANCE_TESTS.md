# v5.0 Implementation Acceptance Tests

A roadmap item is complete only with recorded environment, pinned versions, commands, fixtures, outputs, logs and human review.

## Reference intelligence
- Resolve exact benchmark URLs to intended canonical channels.
- Build balanced sample sets and dated public metric snapshots.
- Produce timestamped shot records, contact sheets and style fingerprints.
- Enforce analysis-only reference isolation and final-render rejection.
- Human reviewer traces recommendations to source timestamps.

## Character pilot
- Two original protagonist candidates, one per future channel.
- Turnarounds, expression sheets, body-action sheets and playable clips.
- Identity regression across camera, lighting, wardrobe and five scenes.
- User iteration and explicit freeze workflow.
- Frozen assets cannot be silently overwritten.

## Voice pilot
- Multiple playable auditions per channel using identical scripts.
- Local runtime benchmark and exact model/weight licence review.
- Profile version lock and repeatability comparison.
- Segment regeneration and transcription/timing tests.
- Consent/provenance recorded.

## Naming and branding
- Curated shortlist with exact/fuzzy YouTube searches.
- Handle availability checked through official current UI/API before reservation.
- Similarity/trademark/domain checks recorded with caveat.
- Icons, banners and thumbnail templates use original approved assets.
- Safe-area and mobile-crop tests.

## Content board and scheduler
- Generate 2–4x candidate pool for desired backlog.
- Accept/reject/revise/shortlist/defer/merge operations persist.
- Lock 30–60 ideas to calendar.
- User chooses one/two-week batch.
- Jobs pause/resume/recover and stop gracefully.
- GPU concurrency respects measured resource ceiling.
- No auto-publishing.

## Blender and final quality
- MCP security/telemetry audit and safe-mode test.
- Deterministic CLI shot build without MCP.
- Cache hit/invalidation and interrupted render recovery.
- Preview/final settings documented.
- Full video passes FFmpeg/ffprobe checks and human playback.
- Human approves character appeal, voice identity, story, animation, thumbnail and complete viewer experience.
