# Brand Naming, Channel Identity and Thumbnail System

## Brand separation
"His Story" and "Her Story" are benchmark labels only. Final channel names, handles, logos, icons, banners, typography and visual identity must be original.

## Naming and availability workflow
Generate a curated shortlist and score memorability, pronunciation, spelling, emotional fit, distinctiveness, searchability and international readability. For every candidate:
1. Search YouTube for exact display name, exact handle and close variants.
2. Check handle availability using the current official YouTube Studio/account flow or supported API evidence.
3. Search web/social platforms for confusingly similar creator/brand use.
4. Check relevant trademark databases and domains.
5. Record query, date, result, conflicts and confidence.
6. Recheck immediately before user reserves the handle.

Display names are not necessarily unique; @handles are YouTube's unique identifiers. Public search absence does not guarantee global/legal availability. Report "no conflict found in checks performed", not absolute worldwide uniqueness. User reserves the final handle in YouTube Studio.

## Channel visual package
Create original icon/avatar, banner/cover art, logo/wordmark, typography and colour rules, safe areas, profile crops, optional intro/outro, thumbnail templates and export presets after names and characters are locked.

## Thumbnail research and production
Reverse-engineer layout principles: subject scale, face placement, eye direction, silhouette, background separation, contrast, colour hierarchy, text density, crop and visual promise. Create original thumbnails from approved 3D renders and original environments.

Each template specifies 16:9 canvas, mobile-safe crop, subject zones, eye-line/gesture, depth/contrast, text limits, typography, palette, expression/props, logo placement, version and channel ownership. Generate multiple variants for human review; never select solely by an AI score.

## Brand lock
Freeze names/handles, logo, palette, typography, channel art and thumbnail grammar as versioned brand packages. Changes create a new candidate and approval cycle.
